# 🎯 Student Mental Wellness & Productivity Tracker

A web-based platform designed to help students manage their study routines, track their mental wellness, and stay consistently productive — all in one place.


## 📌 Features

- ✅ *Task Management* – Add, edit, delete tasks with deadlines  
- ✅ *Mood Tracking* – Log your daily mood and track mental wellness over time  
- ✅ *Study Logs* – Record study hours and visualize weekly progress  
- ✅ *Browser Notifications* – Get timely reminders for upcoming tasks  
- ✅ *Google Login* – Simple and secure authentication via Google  

## 🧰 Tech Stack Used

### 🔹 Frontend
- HTML, CSS, JavaScript

### 🔹 Backend
- JavaScript (Node.js)

### 🔹 Database & Hosting
- Firebase (Realtime Database + Hosting + Authentication)

### 🔹 Notifications
- Browser Notifications API

## ⚙ Implementation Overview

- Users sign in via *Google OAuth*
- Task data, mood entries, and study logs are stored in *Firebase Realtime Database*
- Notifications are triggered using the *Browser Notification API*
- Real-time UI updates using vanilla *JavaScript* and Firebase listeners
